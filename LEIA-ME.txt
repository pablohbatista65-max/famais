FAMAIS MÓVEIS ARTESANAIS — SITE ESTÁTICO

COMO ABRIR NO COMPUTADOR
1. Extraia o arquivo ZIP.
2. Abra a pasta que contém os arquivos do site.
3. Dê dois cliques em index.html.

Não é necessário instalar Node.js, npm, Docker ou banco de dados.

COMO PUBLICAR NO GITHUB
1. Abra o repositório famais.
2. Envie os arquivos atualizados para a raiz do repositório.
3. Confirme as alterações em Commit changes.
4. Aguarde a atualização do GitHub Pages.
5. Abra o site e atualize com Ctrl + F5.

ENDEREÇO ATUAL
https://pablohbatista65-max.github.io/famais/

ARQUIVOS PRINCIPAIS
- index.html: estrutura e conteúdo do site.
- styles.css: aparência e responsividade.
- catalogo-2026.js: lista atual de 53 produtos.
- data.js: arquivo da lista antiga, não carregado pela página.
- app.js: catálogo, pesquisa, filtros, carrinho, modal e WhatsApp.
- logo-famais.svg: logotipo.
- catalogo-2026-pXX-rX.jpg: fotos dos produtos do catálogo 2026.
- capa-*.jpg: fotos da capa animada.
- produto-01.jpg até produto-20.jpg: fotos usadas em outras seções.
- robots.txt e sitemap.xml: configuração para mecanismos de busca.

COMO EDITAR PRODUTOS
Abra catalogo-2026.js. Cada linha da lista CATALOG_2026 informa:
- página e posição da foto no PDF;
- nome do modelo;
- categoria;
- material descrito no catálogo.

O código monta automaticamente a referência e o caminho da foto. Os preços
e o estoque não constam do PDF: são tratados como informação sob consulta.
Ao incluir um produto, envie também uma foto com o nome correspondente.

IMPORTANTE
Esta versão não possui painel administrativo, login, servidor ou banco de dados.
As informações do formulário não são armazenadas: elas são enviadas diretamente
para o WhatsApp quando o visitante confirma o atendimento.

Se futuramente for usado um domínio próprio, atualize no index.html, robots.txt e
sitemap.xml os endereços que atualmente apontam para o GitHub Pages.
